# CIMA3D – Prótesis Mioeléctrica

Repositorio central del proyecto CIMA3D para el desarrollo de una prótesis mioeléctrica modular.

Este repositorio integra:
- Diseño mecánico
- Electrónica
- Firmware
- Machine Learning
- Documentación técnica

## Estructura general

- hardware/ → Componentes físicos de la prótesis
- mechanical/ → Archivos CAD, STL y STEP
- electronics/ → Esquemas y PCBs
- firmware/ → Código embebido (ESP32)
- ml/ → Modelos y datasets
- docs/ → Informes, manuales y decisiones

## Flujo de trabajo
- Desarrollo en ramas *-dev
- Integración y validación en main
- Versionado explícito de piezas y diseños
